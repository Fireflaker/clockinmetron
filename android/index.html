Auto clock-in

E.g. Work at 09:00 Mon–Fri. No clock-out needed. If the app was closed at that time, the entry is back-filled at the exact time when you next open it.

    Theme

    Location (for sunrise / sunset)

    Sync (phones + PC, free via GitHub)

    Keeps your data in one private GitHub Gist. Make a token once: pre-filled token page → Generate token. It only needs Gists: Read and write (permissions picker → Account tab). Paste the same token on every device.

    Backup

    Without sync, data lives only on this device (browser storage). Export a backup now and then.

    Install

    Android: Chrome menu ⋮ → Install app (or Add to Home screen).
    iPhone / iPad: open in Safari → Share ⬆ → Add to Home Screen.
    Full-screen, works offline. The installed app has its own storage, so set up Sync inside it.
